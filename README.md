# Education Center CRM & IELTS Mock System

A web platform built with Django for managing education centers, students, attendance, payments, homework, and IELTS mock exams.

## Technologies
- Python
- Django
- SQLite
- PostgreSQL
- HTML
- CSS
- JavaScript

## Features
- Role-based authentication
- Student management
- Attendance tracking
- Homework management
- IELTS Mock Testing
- Payment management
